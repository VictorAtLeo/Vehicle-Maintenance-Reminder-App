Vehicle Maintenance Reminder App Project Outline 

I. Project Description 
	A. The Vehicle Maintenance Reminder app will help vehicle owners manage maintenance and modifications for their vehicles in one mobile application. 
	B. Users will be able to enter vehicle information, track mileage, record maintenance, and view upcoming services. 
	C. Users will also be able to record aftermarket parts and modifications made to their vehicles. 
	D. The application will provide reminders for regular maintenance and maintenance related to modifications. 
	E. The application will keep a history of completed maintenance, repairs, and modifications. 

II. Problem Addressing 
	A. Many vehicle owners have difficulty remembering when regular maintenance is due. 
	B. Important services such as oil changes, tire rotations, fluid changes, and inspections can easily be forgotten. 
	C. Vehicle owners may also have difficulty keeping track of maintenance performed on aftermarket parts and modifications. 
	D. Manufacturer maintenance schedules may not include maintenance needs for aftermarket parts or modifications. 
	E. Keeping maintenance and modification records in different locations can make it difficult to know what has been installed or serviced. 
	F. The application will address these problems by allowing users to manage regular maintenance, modifications, and related maintenance records in one location. 

III. Platform 
	A. The application will be developed for Android devices. 
	B. Android Studio will be used as the primary development environment. 
	C. Java will be used for application development. 
	D. Firebase may be used for cloud storage and data management. 

IV. Front End and Back End Support 
	A. Front End 
		1. Android Studio will be used to create the application's user interface. 
		2. The interface will include screens for the dashboard, vehicles, vehicle details, adding maintenance, and maintenance history. 
		3. The interface will be designed to make upcoming maintenance and vehicle information easy to find. 
		4. Users will be able to navigate between their vehicles, maintenance records, and modifications. 
	B. Back End 
		1. Firebase may be used to store vehicle information and maintenance records. 
		2. The application will store information such as mileage, maintenance dates, services performed, and modifications. 
		3. Cloud storage could allow users to access their vehicle information across supported devices. 

V. Functionality 
	A. Users will be able to add and manage vehicles. 
	B. Users will be able to enter vehicle information and current mileage. 
	C. Users will be able to add completed maintenance and repairs. 
	D. Users will be able to record aftermarket parts and vehicle modifications. 
	E. Users will be able to record when modifications were installed. 
	F. Users will be able to associate maintenance with specific modifications when applicable. 
	G. The application will display upcoming maintenance. 
	H. The application will provide reminders for upcoming services. 
	I. Users will be able to view their maintenance and modification history. 
	J. The application may eventually use mileage and previous records to help estimate future maintenance needs. 

VI. Design and Wireframes 
	A. A physical wireframe was created first using pen and paper. 
	B. The physical wireframe was used to plan the application's layout and navigation before development. 
	C. The digital wireframe was recreated using Figma. 
	D. The planned screens include: 
		1. Home or Dashboard 
		2. Vehicles 
		3. Vehicle Details 
		4. Add Maintenance 
		5. Maintenance History 
	E. The Home screen will provide a quick overview of the selected vehicle and upcoming maintenance. 
	F. The Vehicle Details screen will provide information about the vehicle, including mileage and modifications. 
	G. The wireframes will provide a visual plan for the application's user interface before coding begins. 

VII. Project Goals 
	A. Create an easy-to-use Android application for managing vehicle maintenance. 
	B. Make maintenance information easy to access and understand. 
	C. Allow users to track aftermarket parts and modifications that may not be included in standard maintenance schedules. 
	D. Provide useful reminders for upcoming vehicle services. 
	E. Keep maintenance, repair, and modification information organized in one application. 
	F. Develop the application using proper software development practices throughout the term.
